# ⚡ Jarvis Trading Bot

Python bot for crypto analysis + trading signals. Built while learning APIs + automation.

> ⚠️ Educational only. Not financial advice. Trading is risky.

### What Jarvis does right now:
- Fetches live crypto prices from Binance
- Calculates RSI signals 
- Prints BUY/SELL alerts to terminal

### How to run:
1. pip install ccxt pandas ta 
2. Create .env file with your API keys
3. python bot.py

### Project Structure:
bot.py public.txt - Main bot code
